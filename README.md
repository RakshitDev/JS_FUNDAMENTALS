## 💡 How to Use This Repository

The best way to use this repository is:

### 1. Learn the concept

Read the explanation and understand what the feature does.

### 2. Look at the examples

Run the code yourself instead of just reading it.

### 3. Experiment

Change the values and see what happens.

For example:

```javascript
const user = {
  name: "Rakshit",
  age: 24
};

console.log(user.name);
```

Don't stop there.

Try:

```javascript
console.log(user.age);
console.log(user.email);
```

Then try adding new properties and modifying existing ones.

### 4. Solve problems

After learning a concept, write your own examples and small problems.

### 5. Understand the "why"

Ask yourself:

> Why does JavaScript behave this way?

This repository focuses heavily on understanding the **why behind JavaScript**.

## 🧠 Important Philosophy

Learning JavaScript is not about remembering hundreds of methods.

It's about understanding the fundamentals well enough that you can reason about your code.

For example, instead of only memorizing:

```javascript
const [first, ...rest] = numbers;
```

understand:

* What destructuring is
* What the rest operator does
* Why `...` behaves differently in different contexts
* What values are actually being assigned

Once the fundamentals are clear, learning frameworks and libraries becomes much easier.

## 🛠️ Running the Examples

Make sure you have Node.js installed.

Check your installation:

```bash
node --version
```

Then run a JavaScript file:

```bash
node filename.js
```

For example:

```bash
node JSFundamentalsOne/example.js
```

You can also run examples directly in the browser console.
